# 테이블 전체 헤더 배경색·굵기 일괄 편집 설계

## 목적

설문 빌더에서 기본 열 헤더와 다중 헤더 전체에 동일한 배경색과 텍스트 굵기를 한 번에
적용한다. 설정은 빌더 편집 화면, 미리보기, 테스트 모드, 실제 응답 화면에서 동일하게
보존한다.

## 범위

- `헤더 일괄 스타일` 기능은 현재 테이블의 모든 기본 열 헤더와 모든 다중 헤더 셀을
  대상으로 한다.
- `텍스트 굵게`와 사용자 지정 배경색을 지원한다.
- HEX 직접 입력과 배경색 초기화를 지원한다.
- 적용 시 기존 헤더별 스타일은 일괄 설정값으로 덮어쓴다.
- Bold 해제와 배경색 초기화도 모든 헤더에 일괄 적용한다.
- 이후 새 헤더를 추가하면 자동 상속하지 않는다. 필요하면 일괄 스타일을 다시 적용한다.
- 개별 헤더 스타일 편집, 글자색, 글자 크기, 행 헤더 스타일은 이번 범위에서 제외한다.
- 모바일 카드의 데이터 행 헤더는 `TableCell` 기반이므로 이번 열 헤더 스타일 대상이
  아니다.

## 데이터 모델

기존 개별 셀 스타일 필드와 이름을 통일한다.

```ts
interface TableColumn {
  textBold?: boolean;
  backgroundColor?: string;
}

interface HeaderCell {
  textBold?: boolean;
  backgroundColor?: string;
}
```

기본 단일 헤더는 `tableColumns`, 다중 헤더는 `tableHeaderGrid` JSONB 내부에 저장한다.
PostgreSQL 컬럼과 Drizzle 마이그레이션은 추가하지 않는다.

기본값은 `textBold = false`, `backgroundColor = undefined`이다. 일괄 적용 시 기본값은
선택 속성을 제거해 기존 데이터 크기와 하위 호환성을 유지한다.

## 편집 UI

테이블 구조 편집 영역의 헤더 관련 조작부에 `헤더 일괄 스타일` 버튼을 추가한다. 버튼을
누르면 전용 다이얼로그를 열고 다음 필드를 표시한다.

- `텍스트 굵게` 토글
- 사용자 지정 색상 선택기
- HEX 직접 입력
- `배경색 없음` 초기화
- 현재 입력값을 반영한 미리보기

색상 프리셋은 제공하지 않는다. 기존 셀 스타일과 동일하게 `RGB`, `RRGGBB`를 허용하고
`#`는 생략할 수 있다. 저장 시 대문자 6자리 `#RRGGBB`로 정규화한다. 잘못된 HEX는
적용하지 않고 다이얼로그에 오류 상태를 표시한다.

다중 헤더가 없는 표에서도 같은 버튼을 제공한다. 다중 헤더가 생성된 표에서는
`tableColumns`와 `tableHeaderGrid` 양쪽을 모두 갱신해, 다중 헤더 해제 후 단일 헤더로
돌아가도 동일한 스타일이 유지되게 한다.

## 상태와 저장 흐름

`useTableEditor`에 전체 헤더 스타일 적용 동작을 추가한다.

1. 다이얼로그가 Bold와 배경색 초안을 관리한다.
2. 적용 시 모든 `currentColumns`를 순회해 두 스타일을 갱신한다.
3. `currentHeaderGrid`가 있으면 모든 `HeaderCell`도 같은 값으로 갱신한다.
4. 열과 헤더 그리드 ref/state를 함께 갱신한다.
5. 기존 `onChange` 경로로 `tableColumns`와 `tableHeaderGrid`를 질문 상태에 저장한다.

스타일 기본값 적용 시 기존 속성을 삭제한다. 헤더 병합·해제·다중 헤더 저장 흐름은 기존
구조를 유지하며 스타일 필드는 헤더 객체와 함께 복사된다.

## 렌더링

공통 헤더 스타일 헬퍼가 `TableColumn | HeaderCell`에서 다음 표현을 만든다.

- `textBold === true`: 헤더 라벨에 굵은 글씨 적용
- 유효한 `backgroundColor`: 헤더 컨테이너에 인라인 배경색 적용

적용 대상:

- 설문 빌더 테이블 편집 헤더
- `TablePreview`
- `InteractiveTableResponse`
- 모바일 원본 표와 원본 행 보기에서 재사용하는 테이블 헤더
- 테스트 모드와 공개 응답 화면

사용자 지정 배경색은 기존 기본 헤더 배경보다 우선한다. sticky 위치, 테두리, 병합 범위,
선택·조건 버튼은 그대로 유지한다. 글자색은 자동 변경하지 않는다.

## 오류 처리

- 다이얼로그의 잘못된 HEX는 저장을 차단하고 사용자가 수정할 수 있게 한다.
- 헤더가 없는 빈 테이블에서는 버튼을 비활성화한다.
- `tableHeaderGrid`가 없거나 빈 배열이면 기본 열 헤더만 갱신한다.
- 병합 헤더도 하나의 `HeaderCell`로 취급해 병합 영역 전체에 배경색을 적용한다.

## 검증

- 색상 정규화: `RGB`, `RRGGBB`, `#` 생략 입력
- 전체 적용: 모든 `TableColumn`과 모든 `HeaderCell`이 같은 스타일을 받음
- 초기화: Bold와 배경색 속성이 전체 헤더에서 제거됨
- 단일 헤더: `tableHeaderGrid`가 없어도 모든 열 헤더 적용
- 다중 헤더: 병합 헤더를 포함한 전체 그리드 적용
- 저장 왕복: 질문 저장 후 스타일 보존
- 렌더링: 빌더, 미리보기, 실제 응답 화면에서 배경색과 Bold 표시
- 기존 헤더 동작: sticky, 병합, 조건, 열 너비 변경 회귀 없음
- TypeScript, ESLint 및 관련 테이블 테스트
