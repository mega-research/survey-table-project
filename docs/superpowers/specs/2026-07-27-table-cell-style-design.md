# 테이블 개별 셀 텍스트 굵기·배경색 설계

## 목적

설문 빌더의 `셀 내용 편집`에서 선택한 셀 하나에 텍스트 굵기와 배경색을 지정한다. 설정은
빌더 편집 화면, 미리보기, 실제 응답 화면에서 아래 모바일 예외를 제외하고 동일하게 보존한다.

## 범위

- 선택한 `TableCell` 하나에만 스타일을 저장한다.
- `텍스트 굵게`는 `cell.content`로 표시되는 셀 텍스트에만 적용한다.
  입력란의 값과 셀 내부 라디오·체크박스·선택 옵션의 글씨에는 적용하지 않는다. 단,
  `choice_opt`·`ranking_opt`가 질문 옵션으로 변환되는 경우에는 파생 옵션 라벨에 적용한다.
- `배경색`은 선택한 셀의 컨테이너에만 적용한다. 같은 행이나 열의 다른 셀에는 전파하지
  않는다.
- 병합 셀은 하나의 `TableCell`이 차지하는 병합 영역 전체에 배경색을 적용한다.
- 빈 셀과 이미지 등 텍스트가 없는 셀도 배경색을 설정할 수 있다.
- 기존 셀은 스타일 속성이 없으면 현재 모양을 그대로 유지한다.
- 행·열 단위 스타일, 글자색, 글자 크기, 헤더 지정은 이번 범위에서 제외한다.
- 스타일 편집은 셀 내용 편집 모달의 단일 셀에만 제공한다. 드래그 선택 영역의 일괄 스타일
  편집은 이번 범위에서 제외한다.
- 셀 복사·붙여넣기, 영역 복사·붙여넣기, 셀 보관함에는 두 스타일을 셀 데이터와 함께
  복사한다.
- 엑셀·SPSS 내보내기는 기존 데이터 중심 형식을 유지하며 화면 스타일을 반영하지 않는다.

## 데이터 모델

`TableCell` JSONB 타입에 다음 선택 속성을 추가한다.

```ts
textBold?: boolean;
backgroundColor?: string;
```

기본값은 `textBold = false`, `backgroundColor = undefined`이다. 선택 속성이므로 PostgreSQL
컬럼이나 Drizzle 마이그레이션은 추가하지 않는다.

테이블 셀이 일반 보기·순위 문항의 옵션 소스로 변환될 때 스타일을 전달할 수 있도록
`QuestionOption`에도 같은 선택 속성을 추가한다. 수동 옵션 편집 UI에는 스타일 설정을
추가하지 않으며, 이번 범위에서는 `choice_opt`·`ranking_opt` 셀에서 파생된 옵션만 이 값을
가진다.

## 편집 UI

`CellContentModal`의 기존 `컨텐츠 정렬` 영역 인근에 `셀 스타일` 영역을 추가한다.

- `텍스트 굵게` 토글
- 사용자 지정 색상 선택기
- HEX 직접 입력
- `배경색 없음` 초기화

색상 프리셋은 제공하지 않는다. HEX는 `RGB`와 `RRGGBB`를 허용하고 `#`는 생략할 수 있다.
저장 시 대문자 6자리 `#RRGGBB`로 정규화한다. 완성되지 않았거나 잘못된 값은 저장하지 않고
기존 배경색을 유지한다. 저장 전에는 모달 미리보기에서 현재 굵기와 배경색을 즉시 확인할
수 있게 한다.

## 상태와 저장 흐름

기존 셀 편집 흐름을 확장한다.

1. `cellToFormState`가 `TableCell`의 스타일을 폼 상태로 복원한다.
2. `useCellForm`이 두 스타일 필드와 setter를 관리한다.
3. `buildUpdatedCell`이 비기본값만 `TableCell`에 저장한다.
4. 굵기 해제 또는 배경색 초기화 시 기존 셀에 남은 속성을 제거한다.

복사·붙여넣기와 질문 저장은 현재 `TableCell` 객체 전체를 복사하므로 별도 저장 경로를
추가하지 않는다.

## 렌더링

스타일 해석을 공통 헬퍼로 모아 렌더러별 표현 차이를 막는다.

- 텍스트 굵기 헬퍼는 `TextCell`과 인터랙티브 셀의 `CellContentLayout` 라벨에 적용한다.
- 배경색 헬퍼는 개별 셀 컨테이너의 인라인 `backgroundColor`에 적용한다.
- 적용 대상은 빌더 행 편집기, 테이블 미리보기, 실제 응답 테이블, 가상 테이블이다.
- 모바일 카드형 화면은 기존 카드 배경을 유지하고 셀 배경색을 적용하지 않는다. Bold는
  모바일 카드의 해당 셀 텍스트 또는 파생 옵션 라벨에 반영한다.
- 명시한 셀 배경색은 기본 흰색, 응답 완료 녹색, 빌더 선택 파란색, 호버 회색보다 우선한다.
  완료·선택·호버 상태는 배경색을 덮지 않고 기존 컨트롤, 테두리, 링, 아이콘으로 표현한다.
- 글자색은 배경 명도에 따라 자동 변경하지 않고 기존 색상을 유지한다.

## 옵션 소스 전파

- `resolveChoiceOptions`와 `resolveRankingOptionsFromCells`는 셀의 `textBold`와
  `backgroundColor`를 파생 `QuestionOption`에 전달한다.
- `choice_opt`의 PC 테이블 응답에서는 해당 선택 셀의 텍스트와 셀 배경에 두 스타일을
  적용한다.
- `choice_opt`의 모바일 `MobileOptionCard`에서는 카드 배경을 변경하지 않고 옵션 라벨
  Bold만 적용한다.
- `ranking_opt`의 순위 드롭다운은 열린 옵션 목록과 선택 후 닫힌 트리거 모두 선택지의
  Bold·배경색을 표시한다.
- `ranking_opt`의 모바일 참조 카드는 다른 모바일 카드와 동일하게 배경색을 무시하고
  Bold만 표시한다.
- 옵션의 선택·비활성 상태를 나타내는 체크·라디오 컨트롤과 테두리는 기존 디자인을
  유지한다.

## 검증

- 직렬화 테스트: 설정 저장, 기본값 복귀 시 속성 제거, 기존 속성 왕복
- 폼 테스트: 셀 변경과 취소 시 스타일 상태 복원
- 렌더링 테스트: 선택한 셀에만 배경색 적용, 인접 셀 미적용
- 텍스트 테스트: 셀 텍스트만 굵게 표시되고 입력 컨트롤에는 영향 없음
- 병합 셀 테스트: 병합 시작 셀 컨테이너에 스타일 적용
- 상태 우선순위 테스트: 완료·선택·호버 상태에서도 사용자 지정 배경색 유지
- 모바일 테스트: 카드 배경은 기존 유지, Bold만 적용
- 옵션 변환 테스트: `choice_opt`·`ranking_opt` 스타일이 `QuestionOption`으로 전달
- 순위 드롭다운 테스트: 목록과 선택 트리거에 파생 옵션 스타일 적용
- HEX 테스트: `RGB`·`RRGGBB` 정규화, 잘못된 값 미저장, 초기화
- TypeScript, ESLint 및 관련 설문 테이블 회귀 테스트
